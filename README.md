# CmdSwipe

Switch Safari tabs with a Cmd + two-finger horizontal trackpad swipe.

## Privacy Policy

_Last updated: 2026-05-31_

CmdSwipe does not collect, store, transmit, or share any user data.

The extension requires permission to read webpage data for the sole purpose of detecting trackpad wheel events while your chosen activation modifier key is held. No webpage content, URLs, browsing history, form input, passwords, or any other user data is read, transmitted, or persisted by this extension.

User preferences (activation modifier, swipe threshold, swipe direction) are stored locally on your device using the browser's local storage and never leave the device.

The developer does not operate any servers, perform any analytics, or maintain any backend infrastructure related to this extension. There is no telemetry of any kind.

For questions or concerns, open an issue at:
https://github.com/jash-maester/Safari-CmdSwipe/issues
